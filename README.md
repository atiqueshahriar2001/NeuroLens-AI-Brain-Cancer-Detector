# NeuroLens AI

**Explainable and Uncertainty-Aware Brain Tumor MRI Classification System**

NeuroLens AI is a local Streamlit research and education dashboard. It runs a trained PyTorch classifier on a brain MRI and presents an AI prediction, confidence, Monte Carlo Dropout uncertainty, and visual explanations. It does not provide a confirmed medical diagnosis.

## Features

- Automatic checkpoint discovery and architecture selection for Custom CNN, ResNet50, EfficientNet-B0, and MobileNetV3-Small.
- Four class probabilities with MC Dropout mean and standard deviation.
- Predictive entropy and optional calibrated uncertainty labels.
- Grad-CAM++ and Captum Integrated Gradients overlays with an Explanation Agreement Score (EAS).
- CPU and CUDA support, cached model loading, and graceful handling of missing or invalid inputs.
- MRI processing is local to the running application; uploaded images are not written to disk by the app.

## Supported classes

Glioma, Meningioma, No Tumor, and Pituitary. Class order is read from the checkpoint's `class_names` field when present.

## System architecture and workflow

1. On startup, the app searches for `neurolens_best.pth` and loads its state dict.
2. It reads `best_model_name` and constructs the matching checkpoint-compatible architecture.
3. It detects CUDA when available, otherwise uses CPU.
4. The uploaded MRI is converted to RGB and resized to 224×224, converted to a tensor, and normalized with ImageNet mean `[0.485, 0.456, 0.406]` and standard deviation `[0.229, 0.224, 0.225]`.
5. Multiple stochastic inference passes produce mean class probabilities and per-class standard deviations. The highest mean probability determines the AI prediction. Predictive entropy is `-sum(p * log(p + 1e-9))`.
6. When enabled, Grad-CAM++ uses the last convolutional layer, and Integrated Gradients uses Captum with a zero baseline. EAS is the IoU between the maps' top 25% activated regions after downsampling.

## Model loading

The application never requests a model upload. Put the trained `neurolens_best.pth` checkpoint in the repository root:

```text
Neurolens AI/
├── neurolens_best.pth       # Recommended location
├── web_app/
│   └── app.py
└── ...
```

It also searches `models/`, `model/`, and `checkpoints/` in the repository root (and these locations within `web_app/`). The checkpoint should contain `model_state_dict`, `class_names`, and `best_model_name`, as generated by the training notebook. A raw Custom CNN state dict is also supported. The `.pth` file is intentionally excluded from Git; provide it through an approved private artifact or deployment process.

## MRI preprocessing

The inference transform matches the notebook's expected evaluation pipeline: resize to 224×224, `ToTensor`, then ImageNet normalization. MRI inputs are held in memory for inference and are not permanently stored by this app.

## MC Dropout and uncertainty

The app enables dropout modules during repeated model evaluation passes, calculates the mean and standard deviation of each class probability, then restores the model to evaluation mode. Entropy is reported directly. A Low/Medium/High level and reliability label are shown only when optional validation thresholds are supplied; the app does not invent calibration thresholds.

Optional `uncertainty_thresholds.json` format:

```json
{
  "low_thr": 0.2,
  "high_thr": 0.6
}
```

## Explainable AI

- **Grad-CAM++:** backpropagates the predicted class score to the last convolutional layer and overlays the normalized activation map on the original MRI.
- **Integrated Gradients:** Captum attribution from a zero baseline to the normalized input for the predicted class.
- **EAS:** intersection over union (IoU) between each explanation map's top quartile of activated regions. It is a descriptive agreement measure and has no clinical threshold.

Integrated Gradients requires Captum. If it is unavailable or XAI fails, prediction and uncertainty results remain visible.

## Installation

Use a Python version supported by the installed PyTorch and torchvision wheels (Python 3.10–3.12 is a practical choice). Install the packages:

```bash
pip install -r requirements.txt
```

For GPU inference, install the PyTorch and torchvision builds matching the target machine's CUDA setup using the official PyTorch installation selector, then install the remaining packages in `requirements.txt`.

## Run locally

From the repository root (the directory containing `web_app/`):

```bash
streamlit run web_app/app.py
```

The only required upload in the application is an MRI image. The model must already be present at one of the supported checkpoint paths.

## Streamlit deployment

Deploy `web_app/app.py` as the Streamlit entry point, install dependencies from `requirements.txt`, and place the trained checkpoint in the deployment's root `models/` directory or another supported location through your private artifact workflow. Do not commit private or sensitive model artifacts to a public repository. Ensure the deployment has enough memory for the selected model and inference device.

## Troubleshooting

- **Model not found:** check the exact filename `neurolens_best.pth` and one of the supported locations.
- **Unable to load checkpoint:** confirm it is the trained checkpoint and that its architecture metadata and state dict match the model implementation in the notebook.
- **CUDA unavailable:** the app uses CPU automatically; inference may take longer.
- **Integrated Gradients unavailable:** install Captum with `pip install captum` and restart the app.
- **Uncertainty level unavailable:** provide a JSON file containing numeric `low_thr` and `high_thr` calibration values from validation.
- **Image rejected:** use a readable JPEG, PNG, BMP, or WebP brain MRI image.
